# Zepto Sales Dashboard

## 🚀 Live Dashboard

👉 [**View Live Dashboard**](https://iru-bs.github.io/zepto-sales-dashboard/)

An interactive sales analytics dashboard built using HTML, CSS, JavaScript and Chart.js.

## 📊 Project Overview

This project presents an interactive sales dashboard with filters, KPIs, charts, and product-level analysis.

The dashboard covers sales performance from **1 January 2025 to 1 March 2025**.

An interactive sales analytics dashboard built to analyze Zepto-style order data and generate business insights.

## 📊 Project Overview

This project presents an interactive sales dashboard with filters, KPIs, charts, and product-level analysis.

The dashboard covers sales performance from **1 January 2025 to 1 March 2025**.

## 🚀 Features

* Interactive date filtering
* City filtering
* Product category filtering
* Customer type filtering
* Customer segment filtering
* Payment method filtering
* Order status filtering
* Reset filters option
* Net revenue KPI
* Total orders KPI
* Average order value
* Order issue rate
* Average delivery time
* Discount analysis
* Daily revenue trend
* Revenue by city
* Revenue by category
* Revenue by customer segment
* Payment method analysis
* Delivery-time analysis
* Order issue analysis
* Top products by revenue

The dashboard interface and filters are implemented directly in the HTML application.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Chart.js
* Responsive Web Design

## 📈 Dashboard KPIs

The dashboard calculates:

* Net Revenue
* Orders
* Average Order Value
* Issue Rate
* Average Delivery Time
* Discounts Given

The JavaScript dynamically calculates these KPIs based on the selected filters.

## 📊 Visualizations

The dashboard includes:

1. Daily Net Revenue
2. Revenue by City
3. Revenue by Category
4. Revenue by Customer Segment
5. Payment Methods
6. Delivery Time
7. Order Issue Reasons
8. Top Products

## ▶️ How to Run

### Option 1 — Open locally

Download the repository and open:

```text
index.html
```

in any modern web browser.

### Option 2 — GitHub Pages

1. Open the repository.
2. Go to **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, select:

   * Source: Deploy from a branch
   * Branch: `main`
   * Folder: `/ (root)`
5. Click **Save**.
6. GitHub will generate a public website link.
